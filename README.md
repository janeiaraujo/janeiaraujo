## 📌 Featured Open Source

### 🧠 [Incident Intelligence Platform](https://github.com/janeiaraujo/knowledgebase) — `knowledgebase`

> **An incident-driven operational knowledge base** — a "Notion for operations": capture incidents during the emergency, turn them into reviewed KB articles, and find the solution instantly the next time it happens.

- 🔎 Full-text + **AI-powered semantic search**, with a review workflow (draft → review → published)
- 🏢 **Multi-tenant** with fine-grained access control (roles, departments, per-base permissions)
- 📋 **Post-mortem & RCA** with structured templates (Google SRE, Netflix, AWS Well-Architected)
- 🔔 Event ingestion from **Zabbix, Grafana** and other monitoring tools via API tokens
- 🛠️ **Node.js 22 · Fastify 5 · MongoDB 7 · React 18 · Vite** — Docker Compose, CI/CD with GitHub Actions, OpenAPI 3.1 docs and a protected `main` branch
- ⚖️ Self-hosted, bilingual (PT/EN), licensed under **AGPL-3.0**

⭐ Contributions are welcome — check the [open issues](https://github.com/janeiaraujo/knowledgebase/issues) and the [contributing guide](https://github.com/janeiaraujo/knowledgebase/blob/main/CONTRIBUTING.md).
